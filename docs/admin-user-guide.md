# Admin User Guide

## Sign in

Use a magic link or the optional password. Admin routes require the `ADMIN` or `SUPER_ADMIN` role.

Local seed admin: `adam@veganuniversity.test`.

## Today

- Overview counts: members, posts, failed billing events
- Community moderation primitives: report, pin
- Member directory and profiles
- Billing health, MRR, churn, webhook log, reconciliation, manual grants (`/admin/billing`)

## Coming by phase

- Course authoring (Phase 3)
- Automations, AI queue, roadmap authoring (Phase 4+)

Never impersonate a member until impersonation exists with logging and a time limit.
